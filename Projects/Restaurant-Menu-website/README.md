# 🍽️ Restaurant Menu Website

A simple restaurant menu webpage built using **HTML5 and CSS3** as part of a frontend web development assignment.

The website displays food items in different categories, along with descriptions, prices, an About Us section, and restaurant contact details.

## ✨ Features

- Restaurant header with navigation
- Starters, Main Course, and Desserts sections
- Menu cards with food names, descriptions, and prices
- About Us section
- Footer with address, opening hours, and copyright
- Hover effects and Google Fonts styling

## 🛠️ Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, colors, spacing, and hover effects
- **Google Fonts** — Playfair Display and Poppins
- **Unsplash** — Food images
